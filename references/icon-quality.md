# 图标风格与边缘质量

## 按素材判断风格

| 局部风格 | 构建方式 | 边缘要求 |
| --- | --- | --- |
| 扁平填充、几何符号 | 原生几何、布尔运算、少量曲线 | 规则处规整，连续曲线平顺；保留参考中有意的尖角 |
| 线性图标 | 连续路径、统一笔画 | 按参考设置端点及连接；不把所有尖端强制改圆 |
| 渐变、轻立体 | 矢量轮廓与可编辑渐变/阴影 | 外轮廓整洁，同时保留高光、渐变方向和层次 |
| 复杂 3D、真实材质 | 原始或生成位图与独立遮罩 | 清晰透明边缘，无白边/色边；保留自然软阴影和材质细节 |
| 手绘、粗粝、有机造型 | 保留有意笔触的矢量或位图 | 去除新增采样瑕疵；不消除作者有意的不规则形态 |
| 像素风 | 原始像素网格或等效方格结构 | 保留规则阶梯边缘，整数倍查看；不做平滑插值 |

风格不确定时检查放大局部和同组素材，采用保留细节的方式并说明不确定处。参考分辨率不足不能作为臆造细节的依据。

## 图标重建步骤

1. 观察每个独特图标/状态的完整局部、容器边界和符号可见边界。只有原图无法看清或需要描摹时才额外裁切，保留少量边距及坐标；可一次批量裁切，重复素材沿用已有参考。裁切用于观察，不自动作为最终图片交付。
2. 分离容器、符号与装饰效果。参考有渐变圆底时，圆底与白色符号各自可编辑，不能合成粗糙描摹路径。
3. 有原始 SVG 或完全匹配组件时先验证再使用；其次查用户指定素材。无匹配项时按参考几何重建，或对描摹初稿做曲线重构。
4. 对照关键点：宽高比、倾斜方向、端点、圆角、缺口、孔洞、部件间隙、笔画粗细。检查可见形状而不是 SVG viewBox 外框。
5. 保留形状特征完成曲线清理，再按最终尺寸落位。不要用“光滑”掩盖轮廓改变，不要为了提高重叠率保留锯齿。

## 平滑几何图标的清理准则

- 圆和椭圆用真正的圆/椭圆；参考明显不是规则圆时不要机械替换。
- 曲线段之间在需要顺滑的位置保持切线连续。去掉无意义短线段、重复节点、尖刺、自交和意外凹凸。
- 用尽可能少且足够表达轮廓的控制点；不设统一节点数量上限，不逐个像素边缘描点。
- 手柄、勺柄、时针等细部检查粗细和圆头；轮子、头像等规则部件检查圆度。实心剪影的尖角不能靠 stroke-linejoin 自动修复，需要调整轮廓。
- 布尔运算后检查细缝、残留片段和负空间；保留合理可编辑结构，不把整组图标展开成无法理解的海量碎片。
- 不用模糊、羽化、锐化、描边加粗或高分辨率位图覆盖来隐藏路径问题。SVG 只是格式，不能证明边缘质量。
- 原尺寸检查视觉重量、细线清晰度与间隙。仅对需要清晰对齐的水平/垂直细线调整像素落位，不把所有曲线控制点强制吸附整数坐标。

## 排查“锯齿”来源

- 正常抗锯齿和低分辨率预览的像素阶梯不应被误判为路径缺陷。只在用户反馈或整页走查发现具体问题时排查对应图标，不安排独立放大验收步骤。
- 若实际轮廓有小折角、鼓包、波浪或不规则圆头，检查路径节点和切线，重新构建曲线。
- 若符号实际为低清位图，对简单几何图标改用矢量重建；复杂素材检查原始分辨率和遮罩，不假称超分辨率恢复了原始细节。
- 渐变容器的高质量不能抵消内部符号缺陷。容器、符号和效果分别验收。

不要求导出 4× 图标或复制放大图标到验收画板。绘制时观察局部参考即可；参考图放大只用于辨认已有结构，不能产生新的真实细节。
